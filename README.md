# Vaishnavi Birthday ❤️

A romantic birthday website for Vaishnavi Gangurde by Durgesh Jagtap.

## Files

- `index.html` — website structure
- `style.css` — romantic design and animations
- `script.js` — password, countdown, calendar, birthday gate, gallery, music

## Add your photos

Put your photos in the `images/` folder with these exact names:

- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg
- photo6.jpg

## Add your song

Put your MP3 here:

`audio/birthday-song.mp3`

Music is intentionally user-controlled because browsers can block autoplay.

## Password

The romantic lock-screen password is `0703`.

## Development testing

At the top of `script.js`:

```js
const DEV_MODE = false;
```

Set it to `true` temporarily if you want to preview the October 7 birthday page before the actual date. Set it back to `false` before publishing.

## GitHub Pages

Upload the project to your GitHub repository and enable GitHub Pages from the repository's Settings → Pages section, using the `main` branch and root folder.
